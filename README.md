# Hayley's Random Immunity
Ever wanted to play as Ellie from The Last of Us? Want to improve your Multiplayer RP? Ever wished that your character could be unknowingly immune?

Then Hayley's Random Immunity might be for you!

## Details
This is a mod which will give your character a small chance of being immune.
This is not a trait, or knowable state - your character will not know they are immune.

### Sandbox Options
- Immunity Chance (Min: 0.0%, Max: 100.0%, Default: 0.1%)
- ResetID: 0 (Min: 0, Max: 2147483647, Default: 0)
